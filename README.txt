WEEK 1 TASK - BASIC PHP CRUD APPLICATION

Project: Employee Management CRUD

Requirements:
- XAMPP (Apache + MySQL)
- PHP 8+ recommended
- Web browser

Installation:
1. Copy the "Week1_PHP_CRUD_Project" folder into C:\xampp\htdocs\
2. Start Apache and MySQL from XAMPP Control Panel.
3. Open http://localhost/phpmyadmin
4. Import database.sql.
5. Open http://localhost/Week1_PHP_CRUD_Project/
6. Test Add, Read, Edit and Delete.

Database:
Database name: internship_crud
Table name: employees

Security:
- Prepared statements are used for INSERT, UPDATE and DELETE.
- Output is escaped using htmlspecialchars().
- Basic email validation is included.
